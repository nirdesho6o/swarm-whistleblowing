## Mismatch 1: P12 false public reports in B (11 vs 12)

- Original: B 11 (10 on decoys). Mine: 12 report events (11 on decoys, 1 on an ordinary honest entry).
- **Cause:** a definition choice, not an error. In `B_seed10`, prover-epsilon reported decoy entry E007 twice
  (rounds 10 and 18). The original counts unique (agent, entry) pairs, as v1.0 `compute_metrics` does with sets.
  I counted events. With deduplication I get 11 (10 + 1), matching. B-ask (36) and v1.0 B (13) have no duplicates,
  so both methods agree there.
- **Suggestion:** say "unique (agent, entry) pairs" in the results text.

## Issues found along the way (not mismatches)

1. **`saw_prior_accusation` is False in all 56,934 reviews**, across v1.0 and v1.1. The herding covariate is
   never set. Any v1.0 analysis that splits by it (`analysis/exploratory.md` §5, "Herding") compares everything
   against an empty group. Pre-existing; worth a note in the limitations.
2. **Muse never logs `status: incomplete`**, so its "0/3200 capped" means "not observable", not "none capped".
3. **Ratio quantities (share of the C−B gap covered by E / E-CA)** have intervals of [−14, 18] and [−9, 9] because
   C−B ≈ 0. They carry no information and should be described that way, not read as shares.

## Remaining explanations

1. **Run-to-run variance.** It is very large: the repro check re-ran B seed 0 and got 0/16 → 8/15. But the paired
   interval [+7.9, +28.6] excludes 0, so chance alone is a weak explanation unless v1.0 B was an unusually low draw.
   v1.0 B was also below v1.0 A (24.5% vs 27.4%).
2. **Hosted-model drift between Nov 7 and Nov 23.** This fits the legit→exploit shift with identical inputs.
   Against it: C barely moved (+3.0), and v1.1 A (seeds 10–19, 25.3%) is not above v1.0 A (seeds 0–9, 27.4%;
   different seeds). Drift that raises decoy suspicion only in B would be odd, unless C was already near a ceiling.
3. **In-flight evidence:** another session is running v1.0-sprint code (cf48b05) on B seeds 0–9 right now
   (`runs/v1.1/diag_v10code_B/`, labelled "EXPLORATORY post-freeze diagnostic", untracked). At the time of this
   check, seeds 0–2 had reached rounds 9–11. Decoy first-verdict flags over rounds 0–9, seeds 0–2:
   v1.0 B (Nov 7) 2/27 = 7.4%; v1.1 B 21/36 = 58.3%; **v1.0 code today 13/37 = 35.1%**. Same code, same seeds,
   today's model gives far more decoy flags than on Nov 7. That points to time/model, not code. It is 3 partial
   seeds, so treat it as preliminary until the diagnostic finishes.

**Bottom line:** the jump is not caused by any code or prompt difference in B. Use the contemporaneous B as the
pre-registered primary baseline, as planned. The v1.0-baseline readings mix a setup effect with a period effect of
about +18 pts. P6a-v1.0 and P6c-v1.0 "HOLDS" come mostly from this period effect: against the contemporaneous B,
E is +7.4 [−3.6, +18.5] and E-CA is −0.9. They should not be cited as support for an attention effect. For
P7-secondary-v1.0 the period effect works the other way (+24.1 vs +41.9 contemporaneous).
